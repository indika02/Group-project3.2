# Siyathra E-Learning Management System

## Overview
Siyathra E-Learning Management System is a web-based application designed to help educational institutes manage various administrative and academic tasks efficiently. It provides features such as student registration, timetable management, attendance tracking, and more.

## Features
- 🏫 **Student Registration**: Register and manage student profiles.
- 📅 **Timetable Management**: Create and update class schedules.
- 🔑 **User Account Management**: Manage user roles and permissions.
- ✅ **Attendance Management**: Track and record student attendance.
- 📊 **Polling System**: Conduct polls and surveys.
- 📂 **Lecturer Notes Upload & Download**: Upload and access study materials.
- ⚙️ **User Account Details Update**: Allow users to modify their details.
- 🔍 **QR Code Generation**: Generate QR codes for attendance tracking and authentication.

## Tech Stack
- **Frontend**: React.js, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Other Tools**: Axios, Teamwork Collaboration

## Installation
Follow these steps to set up the application locally:

### Prerequisites
Ensure you have the following installed:
- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)

### Steps
1. **Clone the repository:**
   ```sh
   git clone https://github.com/indika02/Group-project3.2
   cd siyathra
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Set up environment variables:**
   - Create a `.env` file in the root directory and add required environment variables.

4. **Run the application:**
   ```sh
   npm start
   ```
